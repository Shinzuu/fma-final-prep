# FMA final: study guide

A single-page, printable study guide for the **Financial & Managerial Accounting** final.

**Read it here: <https://shinzuu.github.io/fma-final-prep/>**. It is part of the [QuickXS](https://quickxs-pwa.pages.dev/) study set.

## What's inside

16 topics, about 32 printed pages. Each topic follows the same cycle: learn, worked example, slide problems, practice, MCQ, then answers.

| Chapter | Topics |
|---|---|
| 22 Cost-volume-profit (20 marks) | cost behaviour and high-low · CVP income statement · break-even, target net income, margin of safety · CVP with changes · absorption vs variable costing |
| 10 Plant assets (10 marks) | cost of plant assets · depreciation (straight-line, units-of-activity, declining-balance) · disposal |
| 6 Inventories | FIFO / LIFO / average-cost · perpetual vs periodic · ownership and inventory errors |
| 4 Completing the cycle | adjusting entries and the worksheet · closing entries and the accounting cycle · classified balance sheet |
| 5 Merchandising | perpetual purchase and sale entries · multiple-step income statement |

Page 1 ranks the topics. A topic gets ★★★ when both class topic lists name it.

All the numbers were recomputed two separate ways before they went in. Every table total is checked at build time.
The guide works offline and has a line-by-line reader: use the arrow keys.
